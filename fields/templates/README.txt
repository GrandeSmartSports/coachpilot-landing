Field Command — Template Pack
==============================

Three files to load your league into Field Command in about 10 minutes:

1. bls-coaches.csv   →  Head coaches (name, email, team, phone)
                        Drop into Admin Console → Coaches → Bulk import
                        Each coach gets an emailed invite to set their own PIN.

2. bls-board.csv     →  Board directory (name, role, email, phone, notes)
                        Drop into Admin Console → Board contacts → Bulk import
                        Shows on every coach's hub landing.

3. Field schedule    →  Your existing Excel or CSV works as-is.
                        Drop into Admin Console → Import from Excel
                        The system auto-detects fields, teams, and time slots.

Every file only needs the required columns filled — extra columns are ignored,
extra rows are fine. Delete the example rows before you upload.
